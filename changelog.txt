v0.1.33.7a
- Reworked Simple Favourites around Kodi Python 3 APIs.
- Added four fixed top-level categories: Filme, Serien, Musik, TV-Server.
- Added Kodi context-menu action: Promote to Favorite.
- Stores the original target URL unchanged, including plugin:// and PVR parameters.
- Added persistent JSON data model with schema versioning.
- Added editable nested folders, rename/delete, move, rename and remove favourite actions.
- Duplicate promotion updates the existing shortcut instead of creating a duplicate.
- Removed obsolete xbmcswift2/requests/RPC runtime dependencies.
- Added deterministic addon ZIP build script.

Kodi manifest version: 0.1.33~alpha7 (Kodi-compatible representation of v0.1.33.7a).
